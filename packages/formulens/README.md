# Formulens

Local equation-to-LaTeX recognition with a Linux-first CLI.

This package currently contains the generated CLI scaffold. Capture, OCR,
daemon mode, and clipboard integration are not implemented yet.

From the repository root:

```bash
uv sync --all-packages
uv run --package formulens formulens
```

The command currently prints `Hello from formulens!`.

See the [project repository](https://github.com/HYP3R00T/formulens) for development
setup and documentation.
