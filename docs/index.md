# Formulens

Local equation-to-LaTeX recognition with a Linux-first CLI.

The repository currently contains a Python 3.14 workspace with a single
`formulens` package. Its generated CLI prints a greeting; equation recognition,
capture, daemon mode, and clipboard integration are not implemented yet.
